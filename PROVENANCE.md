# Project provenance

This repository packages Alexander Gaspar Manuel's local coursework project for a technical portfolio. Original course materials may include supplied scaffolding; this repository does not claim that every line was independently authored.

## Author-reported contribution and original outcome

In September 2026, Alexander clarified that the original project used both a distance sensor and an accelerometer, with the goal of detecting object separation and warning of a potential collision. Distance-sensor integration was unsuccessful, and the project continued with the accelerometer only. The distance-sensor failure cause has not been established.

Alexander reported that the LEDs, OLED screen, switches and manual crash triggers worked on the original physical build. He also confirmed that moving or shaking the accelerometer automatically changed the warning/crash state on the board. These statements are the author's retrospective report, not new hardware tests of the published source.

Alexander built the manual crash-detector controls and OLED functionality using AI assistance and personally wired the hardware to the FPGA board. Authorship of the remaining modules is not established by this account.

## Portfolio preparation

In September 2026, Codex assisted with source review, packaging, documentation and the specific corrections/verification described in the README. The original local coursework files were preserved. The state-machine testbench and portable Vivado project script were added during that preparation.
